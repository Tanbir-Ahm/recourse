DejaVu Sans (regular, bold, oblique, bold-oblique) -- version 2.37.

Used by answer_pdf.py so the "download this answer as a PDF" document can print the rupee sign, arrows, curly quotes and
other symbols that the default PDF font cannot. Free software: the DejaVu fonts are derived from Bitstream Vera and are
distributed under the Bitstream Vera / DejaVu licence, which permits use and redistribution (including bundling with an
application). Source: https://dejavu-fonts.github.io/ (obtained via the dejavu-fonts-ttf package on the jsDelivr CDN).

Hindi / Devanagari is NOT covered by these fonts. When Hindi output is added, bundle Noto Sans Devanagari (SIL Open Font
Licence) alongside and register it in answer_pdf._register_fonts.
